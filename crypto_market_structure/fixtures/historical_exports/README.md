# Historical Scanner Exports

These CSV files are legacy scanner snapshots retained as research inputs. They
are not guaranteed to be point-in-time complete, survivorship-free, or
historically aligned with every field used by the canonical reflexivity model.

Use them for local case-study exploration only. A defensible event study must
preserve the original event time, receipt time, source, venue, missingness, and
definition for every observation before treating an outcome as evidence.
